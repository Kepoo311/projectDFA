Cara pakai

  1. Buat state — alat State lalu klik kanvas, atau klik dua kali kanvas. Geser state dengan alat Pilih.
  2. Tandai awal/akhir — klik state, lalu atur di panel Inspektor. State awal punya panah masuk; state akhir berlingkar ganda.
  3. Buat transisi — alat Transisi, klik state asal lalu state tujuan, isi simbol (mis. a atau 0,1).
  4. Uji string — ketik string di konsol bawah, tekan Simulasi atau Langkah untuk satu simbol.
  5. Hapus — pilih state/transisi lalu tekan Delete atau tombol hapus di Inspektor.

Pintasan: 1 pilih · 2 state · 3 transisi · Esc batal · scroll untuk zoom.
